🏛️ Mathematical Formulations & System Architecture

VolVantage is engineered to run high-throughput quantitative volatility forecasting and options liquidity analytics on embedded DuckDB without requiring an external database cluster.

1. Realized Volatility & Jump Decomposition

From 5-minute intraday log returns \(r_{t,i} = \ln(P_{t,i}/P_{t,i-1})\):

$$RV_t = \sum_{i=1}^M r_{t,i}^2, \qquad BV_t = \frac{\pi}{2}\sum_{i=2}^M |r_{t,i}||r_{t,i-1}|, \qquad J_t = \max(0, RV_t - BV_t)$$

2. HAR Cascade & Spillover Extensions

The Heterogeneous Autoregressive model incorporates multi-scale cascade memory and cross-asset correlation/sector spillover factors:

$$RV_{t+1, i} = \beta_0 + \beta_d RV_{t,i} + \beta_w RV_{t,i}^{(w)} + \beta_m RV_{t,i}^{(m)} + \gamma_c \overline{RV}_{t, \text{cluster}(i)} + \varepsilon_{t+1,i}$$

3. Patton (2011) Robust QLIKE Loss & Diebold-Mariano Tests

Standard MSE is asymmetric and non-robust to heteroskedasticity in volatility modeling. We evaluate models using the Quasi-Likelihood robust loss:

$$\mathcal{L}_{QLIKE}(y_t, \hat{y}_t) = \frac{y_t}{\hat{y}_t} - \ln\left(\frac{y_t}{\hat{y}_t}\right) - 1, \qquad DM = \frac{\bar{d}}{\sqrt{\hat{V}(\bar{d})}} \sim \mathcal{N}(0, 1)$$

4. Short-Strangle Multi-Factor Ranking Function

Candidates are prioritized by balancing liquidity depth against portfolio risk and premium yield:

$$\text{Rank Score} = 0.40 \cdot \mathcal{S}_{\text{Liquidity}} + 0.35 \cdot \mathcal{S}_{\text{Risk Safety}} + 0.25 \cdot \mathcal{S}_{\text{Yield}}$$
